# MEE Teacher Panel

Minecraft Education Edition用の教員向けコントロールパネルです。

## 機能

- **一時停止/再開:** ゲーム全体を一時停止したり、再開したりできます。
- **生徒の許可:** ゲームが一時停止している間に、特定の生徒の移動を許可します。
- **集合:** 全ての生徒を教員の場所にテレポートさせます。
- **個別集合:** 特定の生徒を教員の場所にテレポートさせます。
- **アイテム配布:** 全生徒にカメラとポートフォリオ、または振り返り用の本と羽ペンを配布します。
- **チャット:** ゲーム内チャットにメッセージを送信したり、生徒のチャットを閲覧したりできます。
- **プレイヤーリスト:** 接続している全生徒のリストを表示します。
- **プレイヤーマップ:** 2Dマップ上で生徒のリアルタイムの位置を表示します。
- **モブの削除:** 半径50ブロック以内にいるプレイヤー以外のエンティティを全て削除します。
- **飛行能力の切り替え:** 教員に飛行能力を付与または剥奪します。

## セットアップ

### 前提条件

- Node.js
- Minecraft Education Edition

### インストールと実行方法

1.  このリポジトリをクローンします。
2.  依存関係をインストールします:
    ```bash
    npm install
    ```
3.  アプリケーションを起動します:
    ```bash
    npm start
    ```
4.  Minecraft Education Edition内で、以下のコマンドを使用してサーバーに接続します:
    ```
    /connect 127.0.0.1:8080
    ```

## スクリプト

- `npm start`: Electronアプリケーションを起動します。
- `npm run dist`: 配布用にアプリケーションをビルドします。
- `npm run dist:win`: Windows用にアプリケーションをビルdします。

## プロジェクト構成

- `main.js`: Electronアプリケーションのメインエントリーポイント。Minecraftとの通信用のWebSocketサーバーと、Web UI用のExpressサーバーを処理します。
- `public/index.html`: WebベースUIのメインHTMLファイル。
- `package.json`: プロジェクトのメタデータ、依存関係、スクリプトを格納します。
